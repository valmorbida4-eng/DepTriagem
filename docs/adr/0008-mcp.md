# ADR 0008 — Servidor MCP local do DepTriagem

**Status:** aceito.

A CLI expõe `mcp serve` por stdio com mensagens JSON-RPC por linha
e negociação das versões MCP de 2024-11-05 a 2025-11-25. A implementação
atende ao conjunto de ferramentas necessário sem dependências npm de
produção ou listener HTTP.

A consulta aos catálogos usa o perfil existente. Análise de dependências
exige uma pasta ou um repositório configurado no comando de inicialização.
O agente não fornece origens, caminhos de saída, comandos ou credenciais
como argumentos. A análise usa o mesmo OSV-Scanner offline das outras
interfaces, sem consultar modelos configurados no DepTriagem. A saída reduz
o inventário ao necessário para revisar a cobertura e os achados.

A CLI gera trechos de configuração para os clientes. O usuário autoriza o
MCP ao aplicar o trecho no cliente que receberá os dados.

A interface reutiliza o alvo e a configuração da CLI. O diagnóstico
inicia o executável local por stdio com o mesmo alvo e valida a negociação
e as ferramentas anunciadas. O trecho gerado na interface inclui
um identificador da configuração. Ao receber a confirmação de
inicialização do cliente, o servidor registra somente a data da conexão
no perfil local. O diagnóstico interno não atualiza esse registro.
