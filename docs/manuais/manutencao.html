Manual de diagnóstico e manutenção

Guia de manutenção do DepTriagem

Catálogos e GitHub

Confira as duas datas por fonte em Configurações. Se um download falhar, a cópia válida anterior continua disponível. A autenticação usa o GitHub CLI. Confira a conta antes de selecionar um projeto privado.

Instalação e remoção

No Windows use o instalador NSIS. No Linux use AppImage, DEB ou RPM. No macOS abra o DMG e arraste o aplicativo para Aplicativos. Ao remover, encerre o DepTriagem, inclusive o monitor na bandeja do Windows, e remova pelo sistema ou apague a AppImage. Os dados do perfil ficam separados.

Atualizações

Em Configurações → Atualizações, consulte as releases e confira as notas. O aplicativo valida SHA-256. A instalação integrada está disponível no Windows. No Linux, escolha DEB ou RPM na página da release se esse for o formato instalado. No macOS e para AppImage, abra o pacote verificado e substitua a versão anterior.

Diagnóstico

Use Copiar diagnóstico em Configurações → Preferências para obter as versões e as datas dos catálogos. O texto não contém chaves, caminhos ou dados de projetos.

Em decider_unavailable, confira modelo e porta no Launcher. Se o chat retornar HTTP 401, confira a variável de token no processo. Os erros de parecer saem em stderr com o identificador contido no JSON.

Gerar o instalador

Na raiz do projeto, execute npm run dist:win, npm run dist:linux ou npm run dist:mac no sistema correspondente. O instalador inclui o runtime do Electron. Anexe o instalador e seu arquivo SHA-256 à release estável para disponibilizá-la no atualizador.
