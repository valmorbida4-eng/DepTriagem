Manual do usuário

Guia de uso do DepTriagem

Analisar uma aplicação

Em Configurações, instale ou selecione o OSV-Scanner e atualize os catálogos. Na aba Analisar aplicação, escolha Pasta local ou GitHub. Em uma pasta Git local, informe um hash, branch ou tag no campo Commit Git local para usar os arquivos gravados nessa referência. Clique em Analisar dependências. Confira a severidade, o CVSS base e as versões corrigidas publicadas por aviso. Use Salvar relatório JSON para guardar a saída da análise ou Exportar relatório completo para salvar JSON, Markdown e, quando houver, o parecer de IA separado com o SHA-256 do relatório oficial. Em Fontes e ferramentas, confira a data do controle positivo. Se a nova cópia do catálogo falhar nesse controle, a cópia ativa é preservada.

Abrir a interface

No Windows, abra pelo menu Iniciar ou pelo atalho. No Linux, abra pelo menu ou execute a AppImage. No macOS, abra o DepTriagem em Aplicativos.

Na aba Launcher, clique em Abrir Launcher. Se a API de controle estiver ativada, conecte o controle para selecionar, iniciar e parar cada modelo. Para a conexão manual, inicie os servidores no Launcher e informe as portas.

Triar um relato

Em Configurações → Modelos de IA → Configurar Decisor, escolha o provedor e salve o modelo. Em Análise → Triagem de relatos, selecione o Decisor de Configurações ou o Decisor do Launcher. Autorize o envio para usar um provedor externo. Cole o relato ou abra um arquivo UTF-8 com até 16 KiB. Classifique e confira a fila proposta. Quando o resultado indicar revisão humana, encaminhe o relato para uma pessoa.

Revisar dependências

Em Análise → Importar relatório, selecione o relatório OSV e o catálogo KEV. A prioridade máxima indica correspondência com o KEV vigente. Ausência de achados em um relatório importado não comprova cobertura.

Monitorar repositórios

Em Análise → Monitoramento GitHub, liste os repositórios, selecione os desejados ou marque Todos, escolha início e frequência e ative o agendamento. Para atualizar automaticamente os catálogos OSV e CISA KEV, habilite a opção e informe o intervalo em horas. O padrão é 24 horas. O monitor tenta atualizar as fontes vencidas antes de analisar os repositórios. Veja relatórios e novos achados no histórico. No Windows, o monitor continua na bandeja. No Linux e macOS, mantenha o DepTriagem aberto.

Preferências

Em Configurações → Preferências, ajuste o tema e a pasta padrão de relatórios. Em Analisar aplicação → Modelos usados na análise, escolha os modelos já salvos em Configurações ou o modelo principal do Launcher para Agente e Revisor. Em Revisor, escolha Revisor do Launcher (automático) para usar o servidor dedicado quando estiver ativo ou o principal quando ele estiver ausente. Para Decisor, escolha a configuração salva, o Decisor do Launcher ou Desativado. A fila sugerida aparece no resultado e no relatório JSON. Use Buscar modelos ao lado do ID para consultar o catálogo e preencher o campo. Os quatro provedores por CLI são Codex, Claude Code, OpenCode e Antigravity (agy). O OpenCode CLI aceita um ID no formato provedor/modelo. O Antigravity CLI usa o login da CLI ou uma chave GEMINI_API_KEY para a sessão. Em Configurar modelos, salve o par padrão, cadastre as chaves de sessão e teste a conexão. O envio de resumos aos provedores externos depende da autorização na análise.
