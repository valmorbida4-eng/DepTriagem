Manual de integrações

Guia de integrações do DepTriagem

Origens e catálogos

A análise usa a pasta selecionada ou um commit fixo da conta conectada ao GitHub CLI. O scanner usa cópias de lockfiles e catálogos OSV locais. As datas de publicação e de download aparecem em Configurações. O modelo local pode receber detalhes do inventário. Serviços externos recebem apenas um resumo autorizado de cobertura. As sugestões dos modelos ficam separadas dos achados.

Controle do Launcher

O cliente de controle exige um Launcher compatível e seu token dedicado. Cole o token na aba Launcher e use Guardar token para protegê-lo no perfil local. Também é possível fornecer DEPTRIAGEM_LAUNCHER_TOKEN pelo ambiente. Sem essa API, as portas podem ser preenchidas manualmente.

Decisor

A triagem permite usar a porta do Launcher ou de um servidor independente. No modo SystemOne, o cliente usa POST /v1/systemone, com porta padrão 8090. Envia state e uma pergunta choice. Espera answers.routing com a opção e as probabilidades. No modo chat, o cliente usa POST /v1/chat/completions com uma resposta estruturada e valida a fila e as estimativas. Falha de rede, resposta inválida ou tempo limite encaminham o relato para revisão.

Chat opcional

O cliente usa POST /v1/chat/completions, com porta padrão 8080. Quando definido, DEPTRIAGEM_CHAT_TOKEN é enviado no cabeçalho Bearer. O chat recebe apenas a fila e o motivo. O parecer aparece separado na interface. Na CLI, fica no arquivo indicado por --note.

Evidência

A revisão recebe o JSON do OSV-Scanner e um catálogo CISA KEV com data, contagem e CVEs. Um KEV inválido resulta em erro. Evidência vencida desativa a prioridade máxima.

MCP

Em Configurações → Integrações MCP, selecione o cliente e o acesso aos catálogos, a uma pasta ou a um repositório GitHub. Teste o servidor local, copie o trecho e use Abrir local da configuração para localizar o destino. Adicione a entrada deptriagem, recarregue o cliente e confira a conexão nele.

Pela linha de comando, use mcp config CLIENTE --root PASTA na CLI para configurar Codex, Claude Code, OpenCode, Gemini CLI, Antigravity ou VS Code. Para GitHub, use --github dono/repositorio no lugar de --root. Sem origem, o servidor só oferece o status dos catálogos.

GitHub CLI

Autentique-se com gh auth login --hostname github.com --web e confira a conta com gh auth status.
